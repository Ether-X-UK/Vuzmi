# Source licence and release boundary

The founder selected GNU AGPL version 3 on 4 November 2026. Vuzmi uses SPDX identifier `AGPL-3.0-only`: this records version 3 without automatically authorizing later licence versions. Original project code, web/iOS clients, backend, workflow rules and documentation are included. Third-party dependencies, local model weights and vendor tools retain their own terms.

See the complete [LICENSE](../LICENSE) and [GNU's explanation](https://www.gnu.org/licenses/gpl-faq.en.html). Modified network-served versions must provide the source opportunity required by section 13; commercial use is permitted under the licence. The licence selection does not publish a repository, transfer account ownership, approve a production deployment, or authorize outreach.

The checkout includes the source, package lock and local build instructions. The founder authorized publication at [Ether-X-UK/Vuzmi](https://github.com/Ether-X-UK/Vuzmi) on 5 November 2026; its first published application baseline is commit `864b61dbca941f9c42a9324881018fb6590a61c9`. Public distribution must identify the exact source revision and provide its corresponding source, including modifications and necessary build materials. Keep a source link prominent in hosted interfaces. A private GitHub URL is not a public source offer.

The local source packaging command exports only committed tracked source and the licence, with a revision/hash manifest. It requires a clean tracked checkout. Ignored runtime data, credentials, model weights, Pods and build outputs are excluded. Serving that reviewed bundle locally is optional; a network deployment must configure its exact matching source offer before release.

The project currently has no external contributors, CLA, assignment programme or dual-licensing grant. Revisit contribution terms before accepting contributions if a different commercial licensing model is desired. No closed component is required to run the current self-hosted foundation.
